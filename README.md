# Oussama Boumiza - Digital Portfolio

Personal portfolio website built with React, TypeScript, Vite and Tailwind CSS. Sections: hero, about, experience, education, projects, languages, organizations and contact.

## Development

```bash
npm install
npm run dev        # start the dev server
npm run build      # production build
npm run lint
npm run typecheck
```

## Deployment

A GitHub Actions workflow (`.github/workflows/deploy.yml`) publishes the site to GitHub Pages, served on the custom domain set in `CNAME`.
